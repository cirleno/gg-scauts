# AGENTS.md

## What this is
A static, no-framework multi-page site in Portuguese (pt-br): the "Google Glass" educational project from Curso em Vídeo / Gustavo Guanabara. No backend, no templating — plain HTML plus a few vanilla JS files loaded at the end of `<body>`; no inline event handlers remain. The refit (Fases 1-5: metadata, nav generated by JS, a11y, H5BP base + split `_css/`, CDN fonts/FA + explicit image dims) is complete, followed by commits that tweaked the home layout, photo grid, removed the header brand logo, and finally the **v18 redesign**: mobile-first, CSS Grid/Flexbox, container 1200px, cards (`border-radius: 12px` + subtle shadows), light `#f8f9fa` base + automatic Dark Mode (`prefers-color-scheme`), Inter typography, sticky nav with mobile hamburger, and inline SVG social icons (Font Awesome removed).

## Layout and conventions
- Content pages at repo root: `index.html`, `specs.html`, `fotos.html`, `multimidia.html`, `fale-conosco.html`, `google-glass.html`, `404.html`.
- Asset folders are **underscore-prefixed**: `_imagens/` images, `_media/` audio+video, `_javascript/` scripts, `_textos/` raw page text (`*-txt.html`), `_interface/` wireframe screenshots.
- All copy, titles, and nav labels stay in Portuguese (pt-br).
- Orphaned assets were pruned from `_imagens/` (old logo/icon PNGs, unused Glass size variants, footer `*_ico.png` replaced by inline SVG). Only the 22 images currently in use remain.

## Stylesheets (refit gotcha)
- Every page links `_css/style.css` (HTML5 Boilerplate v9 base: reset/`.box-model` normalization) **first**, then `_css/estilo.css` (the site base: tokens `:root`, `#interface`, sticky `#menu` + hamburger, hero `#cabecalho`, layout grid, cards, a11y, dark mode) **plus** one page sheet: `specs.html` and `google-glass.html` → `specs.css`, `index.html` → (base only), `fotos.html` → `fotos.css`, `multimidia.html` → `media.css`, `fale-conosco.html` → `form.css`. Page sheets hold only page-specific rules. Edit `_css/estilo.css` for styles that should apply across pages.
- `_css/style.css` is the HTML5 Boilerplate base — adopted as the reset/boilerplate base in Fase 4 and left as-is.
- `404.html` is self-contained: inline `<style>`, no `_css/` link, Inter/system font fallback.
- Keep `@charset "UTF-8"` lowercase at the top of every `_css/` sheet, and never use `transition: all` — list properties (custom props `--transicao-*`).
- Responsive is **mobile-first** in `_css/estilo.css`: base styles = single column; `@media (min-width: 768px)` keeps `main#conteudo` em **coluna única full-width** (`grid-template-columns: 1fr`). A home usa `section#corpo-full` (artigo) + `#bloco-noticias` (cards `Outras Notícias` e `Novidades no Glass`, 2 colunas ≥768px). All sizes in `rem`/`clamp()` (design tokens `--titulo-*`); page sheets follow (`fotos.css` 2 cols base → 3 cols ≥768px, `specs.css` `#painel-interativo` 2 colunas ≥768px, `form.css`/`media.css` breakpoints simplified).
- Container: `div#interface` is fluid (`width:100%`, `max-width:1200px` via `--max-interface`), full-bleed on mobile, white card with `border-radius:12px` + shadow ≥768px.
- Header is a **Hero** (flex no desktop ≥768px): hgroup esquerdo (title + subtitle via `--titulo-*` tokens, `text-align: left`) com `img#icone` à direita descendo `bottom: -22px` para **sobrepor levemente a borda** entre header e main. `img#icone` tem **altura fixa e igual em todas as páginas** (`min(140px, 14vw)` desktop, `min(120px, 30vw)` mobile, `width: auto`) para o header ter o mesmo tamanho em tudo; proporção preservada automaticamente. No mobile (<768px): bloco centralizado, imagem abaixo do título. `--titulo-*` tokens; `img#icone` tem `filter: drop-shadow`.
- Dark Mode: `@media (prefers-color-scheme: dark)` redefines the `:root` tokens (site bg `#14161a`, surfaces `#1d2026`/`#262a31`, text `#e9ecef`, accent lighter); `color-scheme` is set.

## Navigation / behavior
- The `<nav id="menu">` is **generated once by `_javascript/nav.js`**: it injects the nav as the **first child of `div#interface`** (not `header#cabecalho`), marks `aria-current="page"`, and adds a hamburger `<button id="menu-toggle">` (`aria-expanded`/`aria-controls="menu-lista"`/`aria-label` switched). Mobile: the `<ul>` is hidden unless `.aberto`; it closes on link click or `Esc`. Desktop (≥768px): `ul` always visible row, toggle hidden. Edit `nav.js` to change menu items — not the pages.
- `nav#menu` is `position: sticky; top: 0` inside `#interface`, so it stays pinned while scrolling (opaque `--cor-fundo-menu` + border + shadow).
- Each page's `<img id="icone">` keeps its own default (index→`glass-oculos-preto-peq.png`, specs→`especificacoes-02.jpeg`, fotos→`fotos.png`, multimidia→`multimidia.png`, fale-conosco→`contato.png`) and is the hero visual. There is **no** hover/focus icon-swap anymore (removed in v18).
- `_javascript/funcoes.js` only holds `calc_total()`, used by `fale-conosco.html` (an IIFE binds an `input` listener to `#fcontato`; no inline `oninput` anymore). It computes `#ctot` from `#cqtd` and formats with `Intl.NumberFormat('pt-BR', …currency…)`. `#ctot` is an `<output>` (with `aria-live="polite"`), not an input.
- `google-glass.html` is iframe-only content: no nav, no `#icone`, no scripts.

## Media
- In `multimidia.html`, `_media/` uses legacy multi-source fallbacks (video mp4/ogv/webm; audio mp3/ogg/m4a) — keep all `<source>` entries. `index.html` videos are single-source mp4 only.
- `_css/media.css` restaura o mockup `div#tv-radio` (`_imagens/radio-tv.png`, `aspect-ratio: 900/573`, `max-width: 900px`): `video#filme` fica **absoluto sobre a tela da TV** (`left 8.55% / top 14.6% / 51.1%×45%`, ~16:9) e `audio#musica` **sobre o rádio** (`left 63.8% / top 84% / width 34%`). Posições em porcentagem para manter proporção em qualquer tela — sem breakpoints.
- `video#dia`/`video#demo` (index) live in `_css/estilo.css` with `aspect-ratio: 16/9`, `width: 100%`, rounded + shadow.
- `_javascript/audio.js` is an **empty leftover** (the old JS music toggle); `multimidia.html` plays music via native `<audio controls aria-label="…">`. Don't wire it up or delete it without a committed change.

## Assets/Perf
- Fonts: **Inter** (400/500/600/700) loaded via `<link>` (Google Fonts `/css2`, `display=swap`) with `preconnect` to `fonts.googleapis.com`/`fonts.gstatic.com` in every page `<head>` (incl. `google-glass.html`). `_css/estilo.css` has no `@import`/`@font-face`; brand headings use `'Inter'`.
- Font Awesome was **removed** (no `cdnjs` link, no `<i class="fa…">` anywhere). Footer social links are **inline SVG** (`stroke="currentColor"`, `aria-hidden="true"`) grouped in `.redes-sociais`.
- Every `<img>` has explicit `width`/`height` (matches natural size to avoid CLS) and below-fold images use `loading="lazy"`.

## Serving and build
- **Zero build**: webpack configs and `package.json` were removed. There is no npm/task-runner flow; don't re-add it.
- Preview by serving the repo root statically, e.g. `python -m http.server <port>`. Prefer a server over `file://` for media/forms.

## Metadata
- Every page has pt-br `<title>` + `meta description` + filled OG tags + `theme-color` `#f8f9fa`. `og:url`/`og:image` are relative on purpose (no deployment domain yet) — switch to absolute URLs on deploy.
- `site.webmanifest` is filled (`Google Glass`, `background_color`/`theme_color` `#f8f9fa`).
- `404.html` is pt-br and self-contained (inline `<style>`, no `_css/` link).

## Accessibility
- Every content page has: skip link `<a class="skip-link" href="#conteudo">` (first element after `<body>`), the content wrapped in `<main id="conteudo">`, and the brand `<hgroup aria-hidden="true">`.
- `_css/estilo.css` a11y block: `.skip-link`, `.sr-only`, global `:focus-visible` outline, `[id] { scroll-margin-top: 72px }` (clears sticky nav), `touch-action: manipulation`/`tap-highlight` on menu links/buttons, `prefers-reduced-motion: reduce` block.
- Footer socials are `<a>` with `target="_blank" rel="noopener"` + `aria-label` in pt-br; icons are inline SVG with `aria-hidden="true"`.
- Music/video elements use native `controls` + `aria-label`; no `alt` on `<audio>`/`<video>`/`<source>`.
- Hamburger: `<button>` with `aria-expanded`/`aria-controls` + pt-br `aria-label`, closes on link click/Esc, keyboard reachable.
- `fale-conosco.html`: real `<button type="submit">`, `autocomplete`/`required`/`spellcheck="false"`, labels wrapping or `for`-linked, panini selected. `#ctot` uses `font-variant-numeric: tabular-nums` (form.css). Inputs have visible `:focus` (border + ring).
- `fotos.html` album `<li>`s are focusable via `tabindex="0"`; `fotos.css` mirrors all `:hover` zoom/caption rules with `:focus-visible`.
- Tables become card lists on mobile (`<768px`) via `display:block` on `tr/td` — no horizontal scroll.
- `google-glass.html` and `404.html` are exceptions: no skip link/main/nav (iframe-only content / self-contained).

## Versioning / Tags
- Releases are annotated git tags on `main`, one per completed refit/fix batch, always pushed to `origin`. Currently at **v19** (`refactor/fix:` conformidade com Web Interface Guidelines — alternativa de teclado no painel interativo de specs, `#ctot` como `<output aria-live>` + `Intl` pt-BR, `:focus-visible`, `theme-color` com variante dark, `text-wrap: balance`, `loading="lazy"` no iframe, legenda touch via `hover: none`, meta OG/twitter completas, remoção de 27 órfãos em `_imagens/` e do `.DS_Store`).
- When you finish a batch: create + push an annotated tag (`git tag -a vN -m "descrição"` → `git push origin vN`), bump this AGENTS.md note, then commit. Example: `git tag -a v14 -m "…"`.
- Commit messages are pt-br, Conventional-Commits style (`refactor:`, `fix:`, `feat:`, `chore:`, `docs:`), single short subject (+ optional body), matching the existing `git log`.
- Keep AGENTS.md describing the **current** (tagged) state — it's the runbook for whatever commit an agent checks out.

## Style
- `.editorconfig` is authoritative: UTF-8, LF line endings, 2-space indent, final newline, no trailing whitespace.
- BUT the legacy HTML/CSS/JS files here are **Tab**-indented (each refit kept the tabs, incl. v18). Preserve the local indentation of the file you're editing instead of converting to `.editorconfig`'s 2-space rule — mass-reformatting creates noisy diffs. `.gitattributes` normalizes all text files to LF via `* text=auto`.
